Saniga Zeiterfassung

Nur anschauen (ohne Node.js): Datei demo.html doppelklicken, oder mit Link im Browser (Python nötig):

Ohne Python: im Ordner Saniga in PowerShell:

powershell -ExecutionPolicy Bypass -File .\serve_demo.ps1

Oder doppelklick auf serve_demo.cmd. Link: http://127.0.0.1:8765/demo.html

Mit Python: py serve_demo.py oder python serve_demo.py — mit --lan für andere Geräte im WLAN.

Direkt ohne Server: demo.html öffnen

Mit Server & Datenbank: Docker Desktop + Node.js, dann im Projektordner:

python run.py

Oder manuell im Ordner server:

cd server
npm install
npx prisma migrate deploy
npm run dev

Anschliessend im Browser öffnen: http://localhost:3000 — Registrierung für Mitarbeitende: /join.html

Siehe README.md für Railway und Umgebungsvariablen.
